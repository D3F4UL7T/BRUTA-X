# BRUTA X User Guide (Phase 4)

1. Install deps: `pip install -r requirements.txt`
2. Run: `python main.py`
3. **Assets:** register targets and mark **authorized** before active scans.
4. **Intelligence Graph:** interactive nodes (drag/zoom) from correlated evidence.
5. **Automation:** domain workflow requires authorization checkbox.
6. **Plugins:** disabled until explicitly enabled.
7. **Themes / Profiles:** local preferences only.
